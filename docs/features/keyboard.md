# Keyboard and screen readers

## Procedure

1. Open the popup. Push Tab until each control had the focus.

   Result: Each control shows a clear green focus ring. The order is: Settings,
   then the controls of the cards from top to bottom.

2. On the save question, push Escape.

   Result: The question closes.

3. On the save question, push Tab.

   Result: The focus goes from "Save" to "Not now", "Never for this site" and
   the close button.

4. Start a screen reader (Orca on Linux). Move to the Nodkey button in a field.

   Result: The screen reader says "Fill with Nodkey".

5. Fill a login with the screen reader on.

   Result: The screen reader reads the status card ("Approve on your iPhone",
   then the result), because the card is a polite live region.

6. Open the settings page. Move to the switches.

   Result: The screen reader says the label and "on" or "off" for each switch.
